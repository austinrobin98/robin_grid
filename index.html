Reflection

While creating my CSS Grid Nature Gallery, one of the biggest challenges I faced was remembering the different CSS properties and figuring out which ones worked best together. Sometimes I knew what I wanted the webpage to look like, but I struggled to remember which properties would achieve that result. I learned that experimenting with different settings and checking the results in my browser helped me understand how CSS Grid works. One property I needed help understanding was grid-column, especially when making the featured image span multiple columns. I initially had trouble getting the layout to display properly on smaller screens, but after adjusting the property and testing different browser widths, I was able to fix the issue without media queries. I have seen similar gallery layouts on Instagram, where the images are arranged in organized rows and columns. This assignment helped me understand how websites can display multiple images while keeping their layout responsive and visually appealing.
